# PGBR v0.00.14-LT — Tempestade Eternatus orgânica e privacidade visual experimental

Base: PGBR v0.00.13-LT. Mantém os recursos anteriores, tradução PT-BR, builds Root/sem Root e o mesmo pacote de entrada do Pokémon GO 0.437.0.

## Eternatus — efeitos visuais LT014

- Remove o ciclo mecânico fixo de 10,8 segundos que apagava simultaneamente as camadas de tempestade.
- Vórtice, fumaça, clarões e halo passam a variar independentemente. A fumaça deriva de dentro para fora e se dissipa antes de reaparecer em outro ponto.
- Mantém o centro móvel do joystick, a arte em pé, recorte transparente sobre o mapa, configurações de intensidade e velocidade e a Poké Bola Eternatus.
- Testes de animação Java concluídos e revisão integrada via PR #15.

## Privacidade do treinador — experimental (não validada para lives)

- Interruptor **Ocultar nome visualmente**, disponível na área de Privacidade.
- Nos menus Android do PGBR, o nome é exibido como `*****`.
- A máscara de apresentação do Unity tenta interceptar os setters `UnityEngine.UI.Text.set_text`, `TMPro.TMP_Text.set_text` e `TMPro.TMP_Text.SetText`, somente se o componente, assinatura e código nativo forem validados.
- Troca **exclusivamente** a string do texto visível quando ela for exatamente igual ao nome autenticado do jogador, nunca nomes de terceiros ou textos que apenas contenham esse nome.
- Não modifica nome real, PlayerService, login, ID, autenticação, servidor, RPCs ou dados da conta. O nome autenticado é mantido somente em memória, com limpeza ao trocar de conta/sair.

### Aviso obrigatório

**A substituição ainda não foi testada visualmente no mapa nem no perfil “Eu”.** Não há garantia de cobertura de outras rotas de desenho do Unity, e textos já exibidos podem precisar de uma atualização de tela para refletir a mudança. A restauração imediata de todos os textos ao desligar ainda precisa de validação no aparelho. **Não confiar neste recurso para ocultar o nome durante uma live ou gravação até os testes finais.**

## Validação

- Verificações automatizadas Java e testes C++ de comparação exata em UTF-16.
- Verificação de compilação da fonte C++ de interceptação e controles Android.
- Build completo e funcionamento visual no aparelho precisam ser confirmados antes de declarar proteção para lives concluída.
