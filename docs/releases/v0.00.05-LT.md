# PGBR v0.00.05-LT — atualização automática ao abrir o jogo

- Verificação automática de novas versões quando o jogo com PGBR entra em primeiro plano.
- Janela com a nova versão, alterações, **Baixar atualização** e **Depois**.
- A janela só aparece se a versão pública estável no GitHub Releases for numericamente mais recente do que a instalada e possuir APK sem Root.
- Consultas em segundo plano com intervalo mínimo de seis horas; o mesmo aviso só reaparece após 24 horas.
- Em **Contas e Backup**, a opção **Avisar automaticamente sobre novas versões** começa ligada e pode ser desativada.
- Permanece disponível o botão de verificação manual de atualização.
- Offline e na ausência de Release pública não são exibidos avisos inesperados na inicialização.
- Mantidos os controles de privacidade, melhorias de UX, traduções e sprites do VGP.

## Publicação

O fluxo de build gera **artefatos do GitHub Actions** e não publica automaticamente GitHub Releases. Após validar o APK, é preciso publicar uma Release estável com um APK sem Root como ativo da versão para a janela automática ter o que oferecer. **Nunca publicar o pacote de entrada privado de compilação.** A atualização não é instalação silenciosa; o Android exige consentimento e compatibilidade de assinatura/identidade de pacote.
