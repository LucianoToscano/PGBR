# PGBR-v0.00.01-LT — primeira versão LT

- Identidade visual, títulos, rótulos e instalador Root renomeados para PGBR.
- Pacotes disponibilizados como `PGBR-v0.00.01-LT.apk`, `PGBR-v0.00.01-LT-Root.apk` e `PGBR-v0.00.01-LT-Root-module.zip`.
- Tradução brasileira em desenvolvimento; não representa tradução 100% concluída.
- Jogo base Pokémon GO 0.437.0 ARM64 verificado e assinatura própria mantida.
- O módulo Root mantém identificadores internos legados para compatibilidade com a infraestrutura; o nome exibido passa a PGBR.
- APKs gerados como artefatos privados de teste no GitHub Actions; não publicar o arquivo original do jogo.
- Créditos do projeto original: https://github.com/jpitty03/PGRazor (licença MIT); avisos de terceiros preservados.

Validação em dispositivo Android ainda pendente.
